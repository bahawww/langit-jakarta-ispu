# TUGAS PRAKTIKUM: DARI DATA MENJADI SOLUSI AI
**Pilih kasus nyata, latih model, uji prediksi, dan bangun dashboard.**

---

## A. INSTRUKSI TUGAS
* Kerjakan secara individu dengan memilih satu *use case* dari permasalahan nyata di bidang bebas.
* Tidak hanya menjelaskan konsep, tetapi mengolah dataset, mencoba *training* dan *testing* model *Machine Learning*, menganalisis hasil, serta menyajikannya dalam *dashboard*.
* Tidak perlu *coding*.

---

## B. CONTOH BIDANG USE CASE
* **Telekomunikasi** (mis. prediksi *churn*)
* **Pendidikan** (mis. prediksi kelulusan)
* **Bisnis** (mis. prediksi penjualan)
* **Kesehatan** (mis. prediksi risiko penyakit)
* **Lingkungan** (mis. prediksi kualitas udara)
* **Transportasi** (mis. prediksi kemacetan)

---

## C. TAHAPAN PENGERJAAN

### 01. TENTUKAN USE CASE
* Pilih satu masalah nyata dari bidang bebas.
* Jelaskan masalah dan tujuan prediksi.

### 02. KUMPULKAN DATA
* Cari dataset dari sumber kredibel dan cantumkan tautannya.
* Gunakan Google Sheets untuk memeriksa data, identifikasi *feature* dan *label*.
* Minimal 10 baris data.

### 03. TRAINING & TESTING MODEL
* Gunakan Orange Data Mining atau *tools* gratis lainnya.
* Lakukan *training* dan *testing*.
* Pisahkan data (contoh awal 80:20).

### 04. ANALISIS HASIL TESTING
* Bandingkan nilai prediksi dengan nilai aktual pada data *testing*.
* Tampilkan tabel hasil pengujian.
* Gunakan metrik evaluasi (*accuracy* / MAE, dll).

### 05. BUAT DASHBOARD
* Gunakan Google Looker Studio atau *tools* gratis lainnya.
* Sajikan visualisasi dataset dan hasil analisis.
* Tampilkan indikator utama dan hasil prediksi.

---

## D. TOOLS YANG DIGUNAKAN

### 1. Google Sheets / tools gratis
* Menyiapkan dataset
* Memeriksa data
* Identifikasi *feature* dan *label*

### 2. Orange Data Mining / tools gratis
* *Training* dan *testing* model AI tanpa *coding*
* Visualisasi hasil
* Evaluasi model

### 3. Google Looker Studio / tools gratis
* Membuat *dashboard* hasil analisis
* Visualisasi dataset
* Ringkasan hasil prediksi

---

## E. OUTPUT YANG WAJIB DIKUMPULKAN
> **Format Pengumpulan:** Satu paket tugas di dalam Google Drive: `File Nama_Nim`

1. **Dataset (Excel/CSV)**: Beserta sumber data.
2. **Proses Machine Learning**: File proyek atau tangkapan layar *workflow*.
3. **Hasil pengujian**: Tabel nilai aktual vs prediksi dan metrik evaluasi.
4. **Dashboard**: Tautan atau tangkapan layar *dashboard*.
5. **Kesimpulan**: Penjelasan singkat tentang hasil pengujian dan manfaat solusi bagi masalah yang dipilih.
